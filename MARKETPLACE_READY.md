### Step 1: Create Microsoft Account (5 min)
```
1. Go to https://azure.microsoft.com
2. Sign up for free account
3. Verify email
```

### Step 2: Create Publisher (5 min)
```
1. Go to https://marketplace.visualstudio.com/manage
2. Sign in with Microsoft account
3. Click "Create publisher"
4. Publisher ID: LJ-Tech
5. Publisher Name: LJ Tech
```

### Step 3: Generate Personal Access Token (5 min)
```
1. Go to https://dev.azure.com
2. User settings → Personal access tokens
3. New Token → Name: vsce-publish-token
4. Scopes: Marketplace (Publish)
5. Copy token (save it!)
```

### Step 4: Install vsce & Login (2 min)
```bash
npm install -g @vscode/vsce
vsce login LJ-Tech
# Paste your personal access token when prompted
```

### Step 5: Publish Extension (2 min)
```bash
cd d:\My Data\Projects\Vscode Extension\PairWithCode\pairwithcode
vsce publish
```

### Step 6: Verify (2 min)
```
1. Visit: https://marketplace.visualstudio.com/items?itemName=LJ-Tech.pair-with-code
2. Install from VS Code
3. Test commands work
```
